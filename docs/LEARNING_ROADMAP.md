# 四周学习路线

目标不是把每个库 API 背下来，而是能独立解释一条请求如何从页面进入模型、调用什么工具、经过哪些权限边界、失败时如何定位。

## 第 1 周：跑通并画清楚链路

学习任务：

1. 自己启动项目，观察普通问答和报告生成分别调用哪些工具。
2. 从 `app.py` 开始画出事件流：用户输入 → Agent → 工具 → 回答。
3. 阅读 `agent/react_agent.py`，理解 `messages` 与 `updates` 两种流。
4. 手动修改一个提示词，观察回答风格变化。

验收输出：

- 手画一张不参考 README 的架构图。
- 用自己的话解释 `AgentContext`、`ToolRuntime` 和中间件各自负责什么。

## 第 2 周：吃透 RAG

学习任务：

1. 阅读文档加载、切分、Embedding、Chroma 检索和提示词总结五步。
2. 把 `chunk_size` 改成 300 和 800，各跑一次检索评测并保存结果。
3. 增加 5 条负样本，例如知识库无法回答的问题。
4. 观察检索片段和最终回答不一致时，如何判断是哪一层失败。

验收输出：

- 一张不同 chunk 配置的 Hit@3 对比表。
- 一段解释“检索指标好但答案仍错”的原因。

## 第 3 周：Agent 工程化

学习任务：

1. 阅读工具监控中间件，说明为什么日志不能打印完整用户数据。
2. 给 Agent 增加工具调用次数硬限制，而不是只在提示词里写“最多五次”。
3. 理解会话历史过滤、单轮上下文和长期记忆的区别。
4. 尝试增加一个只读工具，例如查询产品保修期，并补权限测试。

验收输出：

- 一个新增工具的 PR 级改动，包含测试和错误处理。
- 一份不超过 10 行的工具调用安全清单。

## 第 4 周：面试表达与部署

学习任务：

1. 录制两分钟项目讲解，检查是否只会说“用了什么库”。
2. 按 `INTERVIEW_GUIDE.md` 回答十个追问，每个答案控制在 60 秒。
3. 准备 Streamlit Community Cloud 或 Docker 部署方案。
4. 整理简历项目条目，使用“问题 - 方案 - 取舍 - 验证”结构。

验收输出：

- 两分钟讲解视频。
- 一页项目复盘：目标、方案、指标、失败、下一步。
- 三版简历描述：偏算法、偏后端、偏 AI 应用工程。

## 每周复盘模板

1. 本周我能独立解释什么？
2. 哪个结论只是“感觉”，还缺数据？
3. 哪个失败是最有价值的发现？
4. 如果面试官追问成本、延迟、安全或评测，我能否给出边界？
5. 下周只做哪一件最能提升项目竞争力的事？
