# 求职冲刺 5 天计划：学习 + 完善项目一体化

> 目标岗位：AI 应用 / Agent 工程师
> 每天投入：4~6 小时，按 6 小时排
> 原则：先交付，再修行为，最后加深度；不先堆功能。
> 核心闭环：学一个概念 → 在代码里找到它 → 改一处 → 用同一份评测验证 → 写一段面试话 → 提交。

## 2. 每天固定 6 小时闭环

| 时间 | 内容 |
| --- | --- |
| 0:00–0:45 | 学当天概念，只学够改代码的部分 |
| 0:45–1:30 | 在现有代码里定位这个概念 |
| 1:30–2:15 | 先写测试或评测，定义“什么叫对” |
| 2:15–2:30 | 休息 |
| 2:30–3:45 | 小步改代码，一次只改一个概念 |
| 3:45–4:30 | 跑同一份 30 条评测，记录前后数字 |
| 4:30–5:30 | 面试追问 + 把当天素材写进桌面文件 |
| 5:30–6:00 | 复盘 + 提交 |

**每天结束必须同时有三样东西：**

1. 代码/文档变化
2. 评测证据
3. 面试一句话

缺一样，当天不算完成。

## 7. 风险

- 评测集自己标注，有偏；要写标注口径和人工抽检比例
- 模型输出有波动；同一批用例跑两次取均值
- 全量评测有 API 成本；先跑 5 条再跑全量
- Docker 在 Windows 11 家庭版可能需要 WSL2；装不上降级为本地 venv + 录屏
- 不为了功能数量增加未评测的页面
